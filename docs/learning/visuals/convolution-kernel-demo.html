Convolution kernel as a sliding patch

This is a deliberately simplified one-channel example. A 3×3 kernel reads one local 3×3 patch, computes a weighted sum, then moves to the next spatial position. In our real first CNN layer, each filter spans all three RGB channels and its weights are learned during training.
